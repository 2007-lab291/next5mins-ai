# パーツ3 5分タイマーと広告(比べ表 3-1〜3-4)

差し込み口 `#n5-part3`(最初は hidden)。クラス名は `n5-p3-`。

## 出す(emit)
- `n5:timer` `{status:'start'|'tick'|'done', remaining}`(開始時 300、毎秒、0 で done。「もう終わった」は remaining 0 の done)
- `n5:reset` 「やめる」(確認なし)と、終わったあとの「最初に戻る」を押したとき

## 聞く(on)
- `n5:select` 開く。選んだ行動の title(キャラの色)と instruction を出し、タイマー開始、その位置へなめらかにスクロール
- `n5:item-caught` 「品物をキャッチした」の印
- `n5:reset` タイマーを止め、閉じて、中身を消す
- `n5:generating` 同じく閉じる(作り直し中)
- `n5:lang` ボタン・ラベルの文を書き直す

## 行
- 3-1 `n5:select` で開く。
- 3-2 mm:ss のカウントダウン。始めた時刻との差で計算(タブが裏でも狂わない)。一時停止/再開・もう終わった・やめる。
- 3-3 終わり: 「できた!」+ねぎらい+「最初に戻る」。自動では戻らない。音・お知らせはなし。
- 3-4 広告の枠: 高さ90px以上、左上に「広告」ラベル(必ず出す)。`N5.config.adSlotHtml` が空でなければその中身、空なら「広告の枠」の薄い文字。広告ボタンはタイマーのボタンから離している。AdSense の決まりは作る前に社長側で確認が必要。

## 予行
`part3.html` をブラウザで開く。`preview.js` のボタンで試す。「timer = 5 sec」で5秒版(`window.N5_P3_TEST_SECONDS`。本番では未定義)。

## 作り直しの手順
このフォルダの中を消し、`../CONTRACT.md` と比べ表のパーツ3の行を見て、同じファイル構成で作り直す。ほかのパーツは触らない。

## 確かめたことと、残ること(2026-11-04)
- 言語を切り替えると、ボタン・ラベル・「できた!」は書き直す。選んだ行動の題と指示文は AI の答えのデータなので、元の言語のまま(仕様。全パーツの「文字を全部書き直す」約束との関係は秘書室長が決める)。
- 時間: 始めた時刻との差で計算。裏タブから戻った時(visibilitychange)にもすぐ合わせる。時計を進める試験で、300秒と、タイマーが止まっていた間の遅れ取り戻しを確かめた。本物の裏タブでの実機は未確認。
- 広告: `adSlotHtml` は innerHTML で入れる。画像や文字の広告は表示できる。AdSense の標準コードの `<script>` は innerHTML では動かず、さらにサーバーの守り(CSP)が外部 JS を止める。AdSense を使うには、CSP の許可と、script 読み込みの場所の変更が要る(約束の変更。社長・秘書室長の判断)。AdSense の決まりは未確認。
