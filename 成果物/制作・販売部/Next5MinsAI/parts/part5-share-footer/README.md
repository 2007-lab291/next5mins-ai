## 聞く(on)
- `n5:result` : 共有する文を結果から作り直す(バカ・平凡・神の題を入れる)

## 作り直す手順
1. このフォルダの中身を消す。
2. `../CONTRACT.md` と比べ表のパーツ5の節を読む。
3. part5.css・part5.js・part5.html・preview.js・この README を作り直す。差し込み口は `<footer id="n5-part5">`。
4. `part5.html` を開いて予行する(ほかのパーツは触らない)。
