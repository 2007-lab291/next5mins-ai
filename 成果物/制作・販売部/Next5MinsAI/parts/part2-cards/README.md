# パーツ2 3枚のカード

もと: 比べ表 2-1〜2-8、設計書 2章・4章。約束: `../CONTRACT.md`。差し込み口: `<section id="n5-part2" hidden>`。クラス名は `n5-p2-`。

## 出す(emit)
- `n5:generating` `{}` : AIに頼んで待っている(generate を受けた直後)
- `n5:result` `{ result }` : 答えが来た(safety の答えのときも出す)
- `n5:select` `{ model, action }` : カードを1枚選んだ
- `n5:error` `{ message }` : 答えが取れなかった(自分は隠れる)
- `n5:generate` `{ text, lang }` : 「もう一度」ボタン(`N5.state.text` / `lang` で)

## 聞く(on)
- `n5:generate` : 開く → 骨組み表示 → `N5.api.generate` → カード(または safety の message)
- `n5:lang` : 結果があるあいだ、バッジ・ボタン・小見出し・「あなたの状況」の文を書き直す(AIの文はそのまま)
- `n5:reset` : 隠して中身を消す

## 行の対応
2-1 待っている間(薄い3枚の骨組みと Thinking…) / 2-2 答えが来たら開く / 2-3〜2-5 バカ・平凡・神(横3列 768px以上、縦1列、順番はこの順) / 2-6 選ぶボタン(選ぶと印がつき、ほかのボタンと「もう一度」は押せなくなる) / 2-7 situation_summary を小さく出す / 2-8 履歴の保存は**作っていない**(ログインが未接続)。
