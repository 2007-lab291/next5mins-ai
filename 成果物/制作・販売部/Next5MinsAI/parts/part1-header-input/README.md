# パーツ1 ヘッダーと状況の入力

差し込み口: `#n5-part1`(ヘッダー)と `#n5-part1-input`(入力)。クラス名は `n5-p1-`。約束は `../CONTRACT.md`。
予行: `part1.html` を開く(下に「試しの操作」と出来事の一覧が出る)。

## 出す出来事(emit)
- `n5:lang` `{lang}` 言語の選択を変えたとき
- `n5:generate` `{text, lang}` 決定ボタン(入力が空白だけなら押せない)
- `n5:reset` ✕ 消す を押したとき

## 聞く出来事(on)
- `n5:lang` 見出し・入力例・ボタン・プリセット・ログイン小窓の文を全部書き直し、select の値も合わせる
- `n5:generating` 決定ボタンを押せなくして「Thinking… / 考え中…」
- `n5:result` ボタンを戻す
- `n5:error` ボタンを戻し、message を入力欄の下に赤系で出す(次の generate で消える)
- `n5:auth` `{user:{name}|null}` (約束に未掲載。part1内だけの案)ログイン後の見た目(名前ボタン+メニュー My History〔準備中〕/ Log Out)に切り替える。ログイン中は言語の選択を端末に覚える
- `n5:reset` 文字数・エラー・ボタンを戻す(入力の文は消さない。消すのは ✕ のときだけ)
