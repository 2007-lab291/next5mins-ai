# Next5Mins AI(5分後の行動決定AI)サイト 第1版

先延ばしで動けない人が「いまの状況」を書くと、3キャラ(🤪バカ・😐平凡・⚡神)がそれぞれ別々に「次の5分でやること」を出すWebサイト。

- 設計: `成果物/企画部/2026-11-04_Next5MinsAI_企画と設計書.md`
- もとと実物の比べ表: `成果物/企画部/2026-11-04_Next5MinsAI_パーツ別_もとと実物の比べ表.md`
- **作り方の決まり(社長の指示 2026-11-04): パーツを1つずつ別々に作り、それぞれ作り直せるようにする。全部まとめて1つに作らない。** パーツ同士の約束は `parts/CONTRACT.md`。
- AI: Claude Haiku 5.5(社長の答え 2026-11-04)。

## フォルダ

| 場所 | 中身 |
|---|---|
| `index.html` | 全パーツを並べるだけのページ(中身はない) |
| `common/` | 共通: `config.js`(社長が直す設定)・`bus.js`(掲示板)・`samples.js`(にせの答え)・`api.js`(AIの窓口) |
| `parts/CONTRACT.md` | **パーツ同士の約束**(出来事の名前・答えの形・守ること) |
| `parts/part0-page/` | パーツ0 ページ全体(色・幅の変数) |
| `parts/part1-header-input/` | パーツ1 ヘッダーと状況の入力 |
| `parts/part2-cards/` | パーツ2 3枚のカード |
| `parts/part3-timer-ads/` | パーツ3 5分タイマーと広告の枠 |
| `parts/part4-item-throw/` | パーツ4 バカの投げる品物(重ねる層) |
| `parts/part5-share-footer/` | パーツ5 共有とフッター |
| `server/` | AIの窓口(サーバー)。`--dry` はにせの答え。`crisis.mjs` はつらい入力の絞り込み。`mamori.mjs` は `守りの部品/js/` の写し |
| `tests/` | 自動テスト(`node --test tests/server.test.mjs`・`node --test tests/site.test.mjs`) |
| `idiot-lab/` | **バカ工房**: バカだけを取り出して、会話しながら試して育てる道具(2026-11-06。入口は `idiot-lab/README.md`)。サイトのパーツとは別の道具で、パーツには差しこまない |

各パーツのフォルダには、`partN.html`(そのパーツだけを1つで見る予行の画面)があります。ブラウザで直接開けます(サーバーなし)。

## 開き方

| やりたいこと | 動かすもの | 誰が |
|---|---|---|
| 画面を見る(AIなし。にせの答え) | `Next5MinsAI を開く(予行).bat`(= `node server/server.mjs --dry` → http://127.0.0.1:4900/ ) | 社長・AI社員 |
| 本物のAI(Haiku 5.5)で動かす | `Next5MinsAI 本物のAI.bat`(= `node server/server.mjs`)。起動時に鍵を貼る(保存しない) | **社長だけ** |
| パーツ1だけ見る | `parts/part1-header-input/part1.html` をブラウザで開く(ほかも同じ) | 社長・AI社員 |

鍵は、ファイルにも環境変数にも入れない。起動した画面に貼るだけ(メモリの中だけ。閉じると消える)。

## 決まり(AI社員)

- AI社員は、本物のAIを動かさない(動かしてよいのは `--dry`・予行の画面・自動テストだけ。ポートは自分で空いている番号を使う)。鍵を受け取らない・書かない。
- 書き込みは、このフォルダの中だけ。外へつながない(部品のインストール・外のサービス)。新しい道具は社長の承認。
- パーツを直すときは、そのパーツのフォルダの中だけ。共通(`common/`・`part0`・`index.html`・`CONTRACT.md`)を変えるのは「約束の変更」なので、秘書室長が決めて点検に通す。

## パーツを作り直す手順

1. 比べ表の、そのパーツの行(もと)と、`parts/CONTRACT.md` を読む。
2. そのパーツのフォルダの中を消して、約束どおりのファイル(`partN.css`・`partN.js`・`partN.html`・`preview.js`・`README.md`)を作り直す。
3. `partN.html` を開いて、1つだけで動くことを見る。次に予行のサーバーで `index.html` を開いて、ほかのパーツとつながることを見る。
4. 比べ表の「実物」の列と判定を、作った人とは別の人が書く。
