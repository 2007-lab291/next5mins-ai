# パーツX AIの窓口(サーバー)

Next5Mins AI の画面(`index.html` と `parts/`)を配り、`POST /api/next5` で AI の答え(3キャラ+投げる品物)を返す。
もと: 比べ表 `成果物/企画部/2026-11-04_Next5MinsAI_パーツ別_もとと実物の比べ表.md` の X-1〜X-9。設計書 4章・5章・M-3・M-9・M-10。
パーツ同士の約束: `parts/CONTRACT.md`(答えの形は 4)。画面側の入口は `common/api.js`(このパーツの外。変えるときは約束の変更)。

## ファイル

| ファイル | 中身 |
|---|---|
| `server.mjs` | サーバー本体。画面のファイルを配る・`/api/next5` を受ける・回数の上限・AIを呼ぶ |
| `prompt.mjs` | AI への指示文。設計書 5章の原文(英語のまま)+答えの形+安全の決まり+お手本1つ+長さの決まり |
| `validate.mjs` | AI の答えの形を確かめ、決めたキーだけの形にする(だめなら null)。`language` が頼んだ言語と違えば null(X-6) |
| `crisis.mjs` | つらい入力の前の絞り込み。AI に送る前に言葉を見て、当たったら AI を呼ばずに静かな文を返す(X-9)。相談先の欄は空 |
| `mamori.mjs` | 守りの部品の写し。**変えない** |
| テスト | `../tests/server.test.mjs`(予行だけ。外へつながない) |

## 動かし方

| やりたいこと | コマンド(Next5MinsAI のフォルダで) | 誰が |
|---|---|---|
| 予行(にせの答え。外へつながない) | `node server/server.mjs --dry` → http://127.0.0.1:4900/ | 社長・AI社員 |
| 本物のAI(Claude Haiku 5.5) | `node server/server.mjs` → 「ANTHROPIC_API_KEY を貼って Enter:」に鍵を貼る | **社長だけ** |
| 番号を変える | `--port 4901`(0 なら空いている番号) | |
| モデル名を替える | `--model <名前>`(既定 `claude-haiku-5-5`。**未確認の仮置き**) | 社長 |
| 回数の上限を替える | `--per-client N`・`--overall N`(1分あたり。既定 10・60。**仮置き**) | 社長 |
| 自動テスト | `node --test tests/server.test.mjs` | 社長・AI社員 |

起動すると、1行目に `http://127.0.0.1:<番号>/` を出す。このPCの中からだけ開ける(家の Wi-Fi の他の機械からは開けない)。

## 鍵(APIキー)の扱い

- 起動した画面に**貼るだけ**。打った文字は画面に出ない。メモリの中だけに持ち、ファイルにも環境変数にも書かない。閉じると消える。
- 環境変数からは読まない(このPCの Claude Code が、その鍵を使ってしまうことがあるため)。
- 記録(画面に出る文字)に鍵が混じっても、伏せる(`[伏せた]`)。
- **AI社員は、本物のモードを動かさない・鍵を受け取らない。** 動かしてよいのは `--dry` と自動テストだけ。

## 守り

- 画面のファイルは `index.html`・`common/`・`parts/` の中の html・css・js・json・png・svg・ico・txt だけ配る。`server/`・`tests/`・`README.md`・`.bat`・`.md`、上のフォルダへ出る道(`..`・`%2e%2e`)は 404。
- よそのサイトからの POST は断る(403。守りの部品)。守りの札(CSP など)を全部の返事につける。
- `/api/next5`: `text` は 1〜240 文字、`lang` は `en` か `ja`(違えば 400)。中身は 10,000 バイトまで。
- 回数の上限: ひとつの相手(IP)につき 1分 10回、全体で 1分 60回(超えたら 429)。数はこのサーバーが動いている間だけ覚える。
  - **この数字は仮置き**(もとの比べ表・設計書に数字がない。X-4)。値は `server.mjs` の `DEFAULTS` か起動のときの引数で替える。
  - 相手は「つないできた機械の番号」で見分ける。いまはこのPCの中だけで開くので、相手はほぼ1つ=実際は「1分 10回」だけが効く。**公開する・中継(プロキシ)を通すときは、見分け方を作り直す**(そのままだと全員が1つの相手に数えられる)。
- 記録に出すのは「状態の番号とかかった時間」だけ。利用者の書いた文は出さない。AI の API がエラーを返したときも、状態の番号だけ出し、返事の中身は出さない(X-8)。
- つらい入力(死にたい・自殺・自傷・虐待など。en と ja の言葉)は、AI に送らずに、`{ language, safety: true, message }` を返す(予行でも同じ。X-9)。言葉は `crisis.mjs` で足し引きする。取りこぼすより、余分に当たるほうを選んでいる。AI 側の指示(prompt.mjs)の決まりも、そのまま残す(二重の守り)。
  - **相談先の具体名・番号は、まだ入れていない**(`crisis.mjs` の `CRISIS_LINES` が空)。国ごとの窓口は、事実確認(出典と日付)が済んでから入れる。
- 返す状態の番号: 200(答え)・400(text・lang が違う)・403(よそのサイト)・404・405・429(回数の上限)・502(AI のエラー・形がだめ)。画面側(`common/api.js`)は 429・502 を `status` つきで投げる。**画面でどう見せるかは、まだ約束(CONTRACT)に無い**(パーツ2で決める)。
- AI の答えは形を確かめ、決めたキーだけにして返す。形がだめなら1回だけ頼み直し、それでもだめなら 502。AI の側のエラーも 502(中身は利用者に見せない)。

## 費用のめやす(推測。出典: 設計書 M-3。点検室が 2026-11-04 に Anthropic の料金ページで計算。1ドル=150円の仮置き)

- Claude Haiku 5.5: 1回 約0.06〜0.10円(読ませる量 1,500〜4,000トークン、答え 500トークン)。
- 形がだめで頼み直したときは、その回は約2倍。
- いまの指示文は、お手本が1つなので、読ませる量は少ないほう。お手本集を足すと上がる。
- **モデル名(`claude-haiku-5-5`)は未確認の仮置き**。本物を動かす直前に、社長が Anthropic のモデル一覧と料金のページで、正しい名前と料金を確かめる。名前が違うと API が 4xx を返し、全部 502 になる(記録に「モデル名がちがう かもしれない」と出る)。正しい名前は `--model` で渡すか、`server.mjs` の `DEFAULTS.model` を直す。

## Dify に差し替えるとき(比べ表 X-1 は「Dify を通す」)

いまは Dify を通さず Anthropic を直接呼んでいる(比べ表とずれている。🔶)。
`server.mjs` の `callAnthropic(key, model, text, lang)` の1つだけを、Dify を呼ぶ関数に替える。返すものは同じ(AI の答えの JSON。だめなら null)。
行き先を変えるときは、`safeFetch` の `hosts` に Dify の名前を足す(外へつなぐ先が増えるので、社長の承認と点検が要る)。

## まだ無いもの

- ジョークのお手本集(ナレッジベース。X-3)。いまは `common/samples.js` の1つだけ。集め方は設計書 M-6。
- つらい入力の相談先の具体名(国ごと。X-9)。言葉の絞り込みはある(`crisis.mjs`)が、言葉で拾えない書き方は AI まかせのまま。
- 投げる品物の絞り込み(危ないもの・大人向けを、サーバーで落とす)。いまは AI への指示だけ。
- ログインと履歴(X-5)。ユーザーごとの回数の上限(X-4 の後半)も、ログインができてから。
- Dify を通すこと(X-1)。いまは Anthropic を直接呼ぶ。
