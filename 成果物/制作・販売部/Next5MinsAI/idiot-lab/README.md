# バカ工房(Next5Mins AI の「🤪 バカ」「😐 平凡」「⚡ 神」を試して育てる所)

Next5Mins AI の3キャラ(バカ・平凡・神)を1人ずつ取り出して、会話しながら試し、直していくための道具です。画面の「キャラ」の欄で、だれと話すかを選びます。
社長の指示(2026-11-06)「まずはバカの仕組みから作ってください。そのAIと会話が出来るサイトも作って。APIキーを張るから。こいつを試行錯誤して完成までもっていきたい」で作りました。
平凡は、社長の指示(2026-11-06)「ばかは完成です。いつかアップデートするかもしれませんが完成です。次は平凡の作成です。サイトとAPIきーは使いまわして」で、同じ工房に足しました。**サイト・.bat・保存した鍵は、バカと同じものを使います**(鍵を貼り直す必要はありません)。

- バカの決まり: それっぽいけど、本当に関係ないことを言う(企画と設計書 `成果物/企画部/2026-11-04_Next5MinsAI_企画と設計書.md` の 2-1)。バカは完成(2026-11-06)。
- 平凡の決まり: 普通のことを言う。いまから5分で確実に前に進める、小さな一歩を1つ出す。たまに乾いた一言を添える(同じ設計書の 2-2)。品物は投げない。
- 神の決まり: できないけど、できたらすごいことを言う。5分では絶対に無理だが、本当にできたら伝説になる行動を出す。規模の大きさを生かした皮肉を、ときどき挟む(同じ設計書の 2-3)。品物は投げない。社長の指示(2026-11-06)「出来てた。次は神の完成を目指す」で足しました。
- 使うAI: Claude Haiku 5.5(決定事項 2026-11-04 / 8)。
- モジュール同士の約束(作る人向け): `CONTRACT.md`(平凡は 8章、神は 9章)。

## 開き方

| やりたいこと | 動かすもの | 誰が |
|---|---|---|
| 画面だけ試す(AIなし。にせのバカ) | `バカ工房を開く(予行).bat` → 準備ができたら、ブラウザが http://127.0.0.1:4911/ を開く | 社長・AI社員 |
| 本物のバカ(Haiku 5.5)と話す | `バカ工房 本物のAI.bat` → (はじめてのときだけ)黒い画面に鍵を貼って Enter → 準備ができたら、ブラウザが http://127.0.0.1:4910/ を開く(開かないときは、その URL をブラウザに貼る) | **社長だけ** |
| 鍵を新しくする(切れた・取り替えた) | `バカ工房 鍵を貼り直す.bat` → 新しい鍵を貼って Enter(前の鍵と置き換わる) | **社長だけ** |
| 保存した鍵を消す | `バカ工房 鍵を消す.bat` | **社長だけ** |

- 鍵(APIキー)は、はじめて黒い画面に貼ったときに、暗号化して、このPCに保存します(決定事項 N5 2026-11-06 / 2。社長の指示「鍵はパソコンが動いている間だけでなくずっと持ってほしい」)。次からは貼らずに使えます。
  - 置き場所は `%LOCALAPPDATA%\Next5MinsAI\idiot-lab-key\key.dat`(会社のフォルダの外・GitHub には上がらない)。中身は Windows の暗号化(DPAPI。同じ Windows の利用者だけが戻せる)をかけた塊だけです。
  - 同じ Windows の利用者で動くプログラムなら、戻せてしまいます。なので、使う上限を決めた鍵を使い、Anthropic の管理画面で月の上限も決めておいてください。
  - 環境変数・ブラウザには入れません。
  - Windows 以外や、暗号化に失敗したときは、保存しません(そのときだけ貼った鍵で動きます)。
  - 鍵が受けつけられないと出たら(切れた・取り消した)、`バカ工房 鍵を貼り直す.bat` で貼り直します。
- 本物のAIのときは、書いた文が Anthropic に送られます。名前・住所など、個人のことは書かないでください。鍵のような文字が入っていると、送る前に止まります。
- 費用の目安が、答えごとと、上の帯(起動してからの合計)に出ます。**料金は仮置きの値(2026-11 時点の料金表の値)で計算した目安**です。本当の料金は、Anthropic の料金ページで確かめてください。
- 1回の送信の費用は、ふつう 0.1円前後、多くても数円の見込みです(費用点検員の見積もり。1ドル=160円で計算)。
- 起動してからの費用に上限をつけたいときは、`バカ工房 本物のAI.bat` の `node lab\server.mjs --port 4910` の後ろに `--max-usd 1` のように足します(1ドルに近づいたら止まる)。上限の値は社長が決めます。モデル名が料金表に無いときは、この上限は使えません(起動のときに断られます)。
- 月の上限は、社長が Anthropic の管理画面で決めた上限が、別にかかります(設定するのは社長。まだなら、本物を動かす前に設定してください)。

## 試行錯誤のやり方

0. 「キャラ」の欄で、🤪 バカ・😐 平凡・⚡ 神 のどれかを選ぶ(会話・設計図・記録とまとめの、どのタブにもある)。工房を新しくしたあとは、前の黒い画面を閉じてから開き直す(古い黒い画面が動いていると、新しいキャラが出ない)。
1. 「会話」で、いまの状況を書いて、答えさせる。言い返して、会話もできる。
2. 答えごとに「いい・ふつう・だめ」を押して、ひとことメモを書く。
3. 気になったら「設計図」タブで性格や決まりを直して、「下書きとして保存」し、新しい会話で試す。
4. 「記録とまとめ」で「まとめを作る」を押し、出てきた文をコピーして、Claude とのチャットに貼る(まとめは、選んだキャラの分だけ)。
5. Claude が、まとめをもとに、そのキャラの新しい公式の設計図(`v002.json` …)を作る。
6. PC で `/t`(GitHub の変更を、このPCに取り込む合図)を打って取り込み、また 1 から試す。

## 記録と下書きの置き場

会社のフォルダの外(このPCの中だけ)に置きます。GitHub には上がりません。

- Windows: `%LOCALAPPDATA%\Next5MinsAI\idiot-lab\`(`drafts\` にバカの下書き、`average-drafts\` に平凡の下書き、`god-drafts\` に神の下書き、`logs\` に記録。記録は3人分が同じ所に入り、どのキャラかの印がつく)

## 決まり(AI社員)

- AI社員は、本物のAIを動かさない(動かしてよいのは、予行と自動テストだけ)。鍵を受け取らない・書かない。
- 社長が本物のAIを動かしている間は、AI社員は 4910 番に触れない(そこから本物のAPIが使われる)。予行は 4911 番か、テストの中の空いている番号を使う。
- 公式の設計図は上書きしない。直すときは、次の番号の新しいファイルを作る。
- 安全の決まり(つらい内容のときはジョークをやめる・危ない行動や品物を出さない)は、設計図ではなく `brain/prompt.mjs`(平凡は `brain/average/prompt.mjs`。お金を使う・送る・提出する・人を巻き込む一歩を出さない、病気・法律・税金・お金の判断を言わない、も入れた。神は `brain/god/prompt.mjs`。できない理由は規模の大きさにして、まねすると体に危ないことは空想でも出さない・犯罪や暴力や宗教を出さない、も入れた)に固定してある。設計図をどう直しても消えない。設計図の文には「<」「>」「```」を使えない(安全の決まりを打ち消す書き方を防ぐため)。
- つらい内容の入力は、AIに送らずに、静かな文を返す。見分ける言葉の一覧は、Next5Mins AI の本番のサイトと同じもの(`../server/crisis.mjs`)を使う。
