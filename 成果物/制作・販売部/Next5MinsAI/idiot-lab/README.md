# バカ工房(Next5Mins AI の「🤪 バカ」を試して育てる所)

Next5Mins AI の3キャラのうち、**バカだけ**を取り出して、会話しながら試し、直していくための道具です。
社長の指示(2026-11-06)「まずはバカの仕組みから作ってください。そのAIと会話が出来るサイトも作って。APIキーを張るから。こいつを試行錯誤して完成までもっていきたい」で作りました。

- バカの決まり: それっぽいけど、本当に関係ないことを言う(設計書 2-1)。
- 使うAI: Claude Haiku 5.5(決定事項 2026-11-04 / 8)。
- モジュール同士の約束: `CONTRACT.md`。

## 中身

| 場所 | 中身 | たとえ |
|---|---|---|
| `brain/` | ① バカの仕組み(設計図・指示文の組み立て・答えの形・AIの呼び出し・にせのバカ) | バカの「頭」 |
| `brain/blueprints/` | 公式の設計図(`v001.json` …)。バカの性格・ネタの型・決まり・お手本の会話 | バカの「台本の決まり」 |
| `lab/` | ② 窓口(サーバー)。鍵を聞く・会話を覚える・記録をつける | 受付 |
| `web/` | ③ 会話の画面 | 試す部屋 |
| `tests/` | 自動テスト | 点検の道具 |

## 開き方

| やりたいこと | 動かすもの | 誰が |
|---|---|---|
| 画面だけ試す(AIなし。にせのバカ) | `バカ工房を開く(予行).bat` → ブラウザで http://127.0.0.1:4910/ | 社長・AI社員 |
| 本物のバカ(Haiku 5.5)と話す | `バカ工房 本物のAI.bat` → 黒い画面に鍵を貼って Enter → ブラウザで http://127.0.0.1:4910/ | **社長だけ** |

- 鍵(APIキー)は、起動した黒い画面に貼るだけです。ファイル・環境変数・ブラウザには入れません(メモリの中だけ。黒い画面を閉じると消えます)。
- 本物のAIのときは、書いた文が Anthropic に送られます。名前・住所など、個人のことは書かないでください。
- 1回の費用の目安は、画面に出ます(Haiku 5.5 の料金表の値で計算。料金は Anthropic の料金ページで確かめてください)。

## 試行錯誤のやり方

1. 「会話」で、いまの状況を書いて、バカに答えさせる。言い返して、会話もできる。
2. 答えごとに「いい・ふつう・だめ」を押して、ひとことメモを書く。
3. 気になったら「設計図」で性格や決まりを直して、**下書き**として保存し、新しい会話で試す。
4. 「記録とまとめ」で「まとめを作る」を押し、出てきた文をコピーして、Claude とのチャットに貼る。
5. Claude が、まとめをもとに、新しい公式の設計図(`v002.json` …)を作る。
6. PC で `/とる` を打って取り込み、また 1 から試す。

## 記録と下書きの置き場

会社のフォルダの外(このPCの中だけ)に置きます。GitHub には上がりません。

- Windows: `%LOCALAPPDATA%\Next5MinsAI\idiot-lab\`(`drafts\` に下書き、`logs\` に記録)

## 決まり(AI社員)

- AI社員は、本物のAIを動かさない(動かしてよいのは、予行と自動テストだけ)。鍵を受け取らない・書かない。
- 公式の設計図は上書きしない。直すときは、次の番号の新しいファイルを作る。
- 安全の決まり(つらい内容のときはジョークをやめる・危ない行動や品物を出さない)は、設計図ではなく `brain/prompt.mjs` に固定してある。設計図をどう直しても消えない。
- つらい内容の入力は、AIに送らずに、`../server/crisis.mjs` の絞り込みで静かな文を返す(本番のサイトと同じ)。
