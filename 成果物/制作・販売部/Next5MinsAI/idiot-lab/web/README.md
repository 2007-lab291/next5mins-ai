# web/ 画面の部品(③)

サーバー(②)が `/` で `index.html` を、`/web/…` でこのフォルダの中を出します。外の部品は使いません。

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み(上の帯・タブ3つ・各画面)。インラインの script・style は無し |
| `app.css` | 見た目(白が基本、バカの色は黄) |
| `app.js` | 動き。文は全部 `textContent` で出す |

## 画面の部品
- 上の帯: 予行/本物・モデル名・起動してからの合計。予行のときは黄の帯。
- 会話: 設定の行(設計図・言語・考える量・新しい会話)、吹き出し、行動カード、品物の箱、チェックの札、評価ボタン、言い直し、頭の中、入力欄。
- 設計図: 見る設計図の選択、各欄、ネタの型(行の足し引き)、お手本(JSON)、下書き保存、指示文の全文。
- 記録とまとめ: 日数・評価つきだけ・下書き、まとめ、コピー、手順。

## 使う HTTP の道
| 道 | 使う場面 |
|---|---|
| `GET /api/state` | 起動時と下書き保存のあと(設計図の一覧・考える量・合計) |
| `GET /api/blueprint?ref=` | 設計図タブで開く・ネタの型の名前を引く |
| `GET /api/system?ref=&lang=` | 指示文の全文を見る |
| `POST /api/blueprint` | 下書きとして保存 |
| `POST /api/chat` | 送る |
| `POST /api/regenerate` | 言い直させる |
| `POST /api/rate` | 評価の印・メモを保存(印を押したときと、メモを保存したときの2回送ることがある。同じ conv・turn の新しいほうが正) |
| `POST /api/summary` | まとめを作る |
