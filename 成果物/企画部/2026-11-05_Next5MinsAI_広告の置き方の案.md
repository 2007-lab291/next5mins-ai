# Next5Mins AI 広告の置き方と出し方の案

- 作った日: 2026-11-05
- きっかけ: 社長の指示「サイト内に広告の表示の仕方をどこに配置するとか表示方法など良い案を探して」
- 作った人: 調べ=法令・規約確認員(広告の決まり)・市場調査員(似たサイト)。まとめ=秘書室長。
- 立場: **案です。決めるのは社長です。** Next5Mins AI を事業として進めるかも、まだ決まっていません(未決事項147)。
- 確かさ: **このクラウドからは Google・Amazon などの公式のページを直接開けませんでした。** 下の決まりは、すべて検索結果の要約から読んだものです。使う前に、原文と専門家(弁護士・行政書士)で確かめてください。
- 確かさの印: [要約] = 検索結果の要約で読んだ / [未確認] = 根拠が見つからない・記憶による / [推測] = 秘書室長・担当の考え

---

## 1. ひとことで(おすすめの案)

1. **最初は、広告を出さないで始める。** 収入は Amazon の投げる品物だけにする。AdSense(Google の広告)は、審査に通る中身(使い方・よくある質問・プライバシーポリシーなど)をそろえてから申し込む。[推測]
2. **出すときは、スマホで1つ、パソコンで2つまで。** 置き場所は「3枚のカードの下」と、パソコンだけ「画面の左右のあきの、どちらか片方」。[推測]
3. **出さない所を決めておく。** エラーの画面・投げる品物の重なる層には出さない。待ち画面・「できた!」の画面・つらい入力への答えの画面にも、出さないほうが安全。[一部は要約・当てはめは推測]
4. **出し方は、静かに。** 「広告」の印をつけ、大きさを先に決めて空けておき、ボタンから離し、5分の間に出し直さない。[要約・当てはめは推測]

## 2. 画面のどこに置くか

いまの第1版は、広告の枠を、タイマーのボタンの下に約30px はなして置いています(カードの枠を隔てている)。ボタンの近くは押しまちがいを招くおそれがあり、決まりに離す距離の数字は見つかりません。スマホでは指が届く近さなので、場所の見直しをおすすめします。[推測]

```text
 パソコン(幅が広いとき)                     スマホ
+------------------------+------+   +------------------+
| ヘッダー                |      |   | ヘッダー          |
| 悩みの入力欄            |      |   | 悩みの入力欄      |
| カード3枚              | [C]  |   | カード3枚        |
|   (すき間を広く)       | 縦長 |   |  (すき間を広く)  |
| [A] 広告 1つ          | の   |   | [A] 広告 1つ    |
| 5分タイマー            | 広告 |   | 5分タイマー      |
| (タイマーのまわりは無し)| (左右|   | 共有・フッター    |
| 共有・フッター          | の片方)|  +------------------+
+------------------------+------+
```

| 記号 | 場所 | 見られやすさ | じゃまの度合い | 評価 | 気をつける点 |
|---|---|---|---|---|---|
| A | 3枚のカードの下(タイマーの上) | 中〜高。答えを読む数十秒に目に入る [推測] | 中 | **おすすめ** | 4枚目のカードに見えないよう、色・形を変える。「これを5分やる」ボタンから離す。[推測] |
| C | パソコンの左右のあき(中身の幅1024pxの外)の、どちらか片方 | 中 [推測] | 小(目の端) | **おすすめ(パソコンだけ)** | 左右の両方に出すと、A と合わせて3つになる。画面の幅が足りないときは出さない。スマホでは出ない。[推測] |
| B | 5分タイマーの下(いまの場所) | 低〜中。5分の間は画面を見ないのが理想なので [推測] | 小〜中 | 条件つき | ボタンの近くは押しまちがいを招くとされる [要約]。置くならボタンから大きく離し、動かない広告だけ。A と両方はスマホでは多すぎる [推測] |
| D | ページの一番下(フッター) | 低 [推測] | 最小 | 予備 | 収入は少ない見込み [推測] |
| — | 入力欄の上(ページの最初) | 高 | 大 | すすめない | 後から広告が入ると画面がずれて、押しまちがいにつながる [要約。Google の広告タグの手引き] |
| — | スマホの画面の下に追従する広告 | 高 | 大 | すすめない | 大きい追従広告は Better Ads Standards で避ける型 [要約]。下の共有・タイマーのボタンと近い [推測] |
| — | 待ち画面(AIが答えを作っている間) | — | — | **置かないほうが安全** | Google は「中身のない画面」への掲載を不可とし、例にお礼・ログイン・終了・エラーの画面を挙げている [要約]。待ち画面が例に入るかは確かめられない。1ページの中の表示の切り替えにどう当てはまるかも、原文で確かめる [推測] |
| — | 「できた!」の画面(5分が終わったあと) | 高 | 小 | **置かないほうが安全** | お礼の画面に近い。上と同じく、例からの当てはめ [推測]。市場の調べでは「見られやすい」と挙がったが、決まりと合わないおそれがある |
| — | 投げる品物の重なる層・ポップアップ | — | — | **置かない** | ポップアップの中の広告は不可とされる [要約]。Amazon のリンクと見分けがつかなくなる [推測] |
| — | つらい入力への答え(相談先を出す画面) | — | — | **置かない** | 決まりの根拠は見つからない。つらい人に広告を見せない、という会社の判断として [推測] |

## 3. どう出すか(表示の仕方)

| # | 出し方 | 理由と確かさ |
|---|---|---|
| 1 | 枠の左上に「広告」(英語は「Advertisement」)の印を、いつも出す | 広告と中身を見分けられるようにする、とされる [要約]。使ってよい言葉(「Sponsored Links」「Advertisements」など)は、2010年の古い公式ブログにあるだけで、いまの原文では [未確認]。日本語の「広告」「スポンサーリンク」も [未確認]。いまの第1版はすでに出している |
| 2 | 枠の大きさを先に決めて空けておく | 後から広告が入って画面がずれると、押しまちがいと不信につながる [要約] |
| 3 | ボタン・リンクから離す。カードと色・形を変える | ボタンの近くの広告は、押しまちがいを招くとして違反になりうる。意図しなくても通知が来うる [要約]。離す距離の数字は見つからない [未確認] |
| 4 | 5分の間に、広告を出し直さない | 利用者が求めていない再読み込みは不可とされる [要約]。「最初に戻る」で出し直すのがよいかは [未確認] |
| 5 | 急に点滅する広告と、音つきで自動で始まる動画の広告を避ける | Better Ads Standards で避ける型 [要約]。音なしの動画やふつうの動きは、この型に入らない。ただ、気が散りやすい人の声では、点滅や動画そのものが嫌われる [要約。少数の声] |
| 6 | 「押してね」「応援してね」と書かない | 広告に不自然に目を向けさせることは不可とされる。本文は読めていない [未確認] |
| 7 | Amazon の投げる品物には、AdSense とは別に「PR」と Amazon の決まった一文を出す | 日本のステマ規制(令和5年3月28日 内閣府告示第19号。2023-10-01 施行)の対象は、広告主の事業者 [要約]。サイトを作る側にそのまま当たるかは読めていない。米国 FTC の決まりも二次情報だけ [要約]。**当てはめは専門家に確かめる。** Amazon の決まった一文の言葉は [未確認]。示しておくほうが安全 [推測] |
| 8 | 1ページの広告は少なく(スマホ1・パソコン2まで) | 数の決まりは見つからない [未確認]。少なく始めるのが無難 [推測] |

## 4. 広告を出す前に要るもの

| # | 要るもの | 中身 | 確かさ |
|---|---|---|---|
| 1 | AdSense の審査に通る中身 | 1ページだけの道具で、説明が少ないと、不合格になる可能性は高め。「使い方」「よくある質問」「このサイトについて」などの、自分たちで書いたページを足す | 不合格の理由に「最低限のコンテンツ」があることは [要約]。1ページの道具が不合格に「なりやすい」と言い切る根拠はない [推測] |
| 2 | プライバシーポリシー | Google などが Cookie を使って広告を出すことを書く。悩みの文を AI に送ることも書く(企画と設計書 M-8) | [要約] |
| 3 | ads.txt | サイトの一番上の場所に置く小さなファイル。広告を売ってよい会社を示す。無いと警告が出る | [要約] |
| 4 | EU・英国の人への同意の仕組み | EU・英国の人に、一人ひとりに合わせた広告を出すには、Google が認めた同意の仕組み(CMP)が要る。EU・英国は 2024-01-16 から、スイスは 2024-07-31 から。仕組みがないと、合わせない広告になり、収入が減るおそれ | [要約。原文は未確認]。Google 自身の無料の仕組みが認められた一覧に入っているかは [未確認] |
| 5 | サイトの作りの変更 | いまのサイトは、外の部品(Google の広告の部品)を止める守り(CSP)にしている。また、いまの広告の枠は、Google の広告の部品(`<script>`)を入れても動かない入れ方をしている。広告を出すには、この2つを変える。パーツ同士の約束の変更になるので、点検室の安全点検に通す | 社内の作りの事実(パーツ3の README) |
| 6 | 広告の出し分け | 待ち画面・「できた!」・エラー・つらい入力への答えのときは、広告の枠を消す作りにする | [推測] |

## 5. 広告のほかの収入のやり方(参考)

| やり方 | 中身 | 合うか |
|---|---|---|
| 有料版で広告なし | 集中タイマーの pomofocus は、無料版に広告、有料版で広告なし [要約] | 利用者が増えてから [推測] |
| 寄付のボタン | Buy Me a Coffee など。審査なし [要約] | 目立たない所に置くなら合う [推測] |
| EthicalAds・Carbon Ads | 開発者・デザイナー向けのサイトが中心 [要約] | 先延ばしの悩みのサイトは対象外の可能性が高い [推測] |
| Mediavine・Ezoic など | 訪問数の条件が高い(月5万セッション前後など。販売側の記事) [要約] | 始めのうちは合わない [推測] |

## 6. 社長に決めてほしいこと(案まで)

1. 最初は広告なしで始めるか、最初から AdSense を申し込むか。
2. 広告を出すなら、置き場所をどれにするか(おすすめ: スマホは A、パソコンは A と C)。いまのタイマーの下(B)は、ボタンから約30px 離れてはいるが近いので、やめるか。
3. EU・英国の人に広告を出すか(出すなら同意の仕組みが要る)。

---

## 7. 確かめる点(原文か専門家で)

1. AdSense のプログラムポリシーの原文(置き方・再読み込み・押すよう促す文・広告の数・日本語の印)。
2. お礼の画面・待ち画面の扱いが、1ページの中で表示が切り替わるサイトにどう当てはまるか。
3. Better Ads Standards の最新の一覧(betterads.org。2026年に更新があったとの報道は [未確認])。
4. EU・英国の同意の仕組みを、どれにするか。
5. Amazon アソシエイト(日本・米国)の運営規約の、表示の一文と置き場所。
6. ステマ規制・FTC の当てはめ、プライバシーポリシーの文、GDPR(弁護士・行政書士)。
7. 似たサイト(pomofocus など)の実物の広告の位置(このクラウドから開けなかった。社長のブラウザで見られる)。
8. 下の出典のURLは、検索で見つけただけで、開けていない。特に消費者庁と PwC のURLは、正しいページかも確かめられていない。使う前に開いて確かめる。
