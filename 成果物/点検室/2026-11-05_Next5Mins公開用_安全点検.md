# Next5Mins AI 公開用の写し 安全点検の所見(2026-11-05)

- 点検したもの: 公開リポジトリに出す予定の79ファイル(`作る.mjs --public` で作った枝 `public-next5mins` の中身)
- 点検した人: 安全点検員(security-inspector)。作った人(秘書室長)とは別。保存は秘書室長。
- 判定: **直してから**(高を直し、出し方の条件を守れば公開してよい)

## 所見と直し
| 重さ | 所見 | 直し |
|---|---|---|
| 高 | 決定事項 2026-11-05 / 2 に、社長がまだ済ませていないPCとアカウントの守りの作業が名指しで書いてあった | 公開用は、決定を決めた表だけにした(自動で足さない)。この項目は入らない |
| 高(出し方) | 会社のリポジトリを公開にすると、全部の枝と過去の全部の変更が見える | 新しい別のリポジトリに、履歴なしの1回目の保存として出す。作った人の名前は GitHub の公開用アドレス |
| 中 | 開発担当の役の決まりに、中止中の別の仕事の中身が詳しく書いてあった | 公開用の短い版(`Next5Mins枝/公開用_developer.md`)に差し替えた |
| 低 | README と守りの部品の README に、ほかの仕事の名前と、PCの守りの手順書の話 | 公開用では消した |
| 低 | 決定事項に非公開のリポジトリの名前と URL | その決定は公開用に入らない |
| 低 | 事実確認の所見に、クラウドで通信を許している先の話 | 害は小さいので残した |
| 低 | つらい入力を見分ける言葉の一覧(`server/crisis.mjs`)が見える | いまはPCの中だけなので残す。公開のサイトを作る段で考え直す |

## 問題なし
- 本物の鍵は無い(テスト用のにせの値だけ)。社長の個人のこと(本名・メール・住所・学校・アルバイト・家族・健康)は見つからなかった。
- 他人の著作物を写した所は見つからなかった(仕様書そのものの出どころは確かめていない)。
- サーバーのコードは公開してよい(鍵は貼るだけ・このPCの中だけで開く・外へつなぐ先は Anthropic だけ)。

## 確かめていない所
全文を読んだのは記録・決まり・仕様書・サーバーの主なファイル・点検の所見。設計書は一部、パーツの画面・テスト・比べ表・守りの部品のコードは言葉で探しただけ。
