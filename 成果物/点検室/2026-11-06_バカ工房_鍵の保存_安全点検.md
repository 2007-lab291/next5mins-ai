# バカ工房 鍵の保存の安全点検(2026-11-06)

- 点検したもの: 鍵を暗号化して保存する変更(決定事項 N5 2026-11-06 / 2)。`idiot-lab/lab/key-store.mjs`(新しい)・`lab/server.mjs` の起動の所・.bat 4つ・`tests/key-store.test.mjs`・README と CLAUDE.md の鍵の所。
- 点検した人: 安全点検員(作った人とは別。読み取りだけ)。
- 結果: **合格。高0・中0・低5。**
- よかった点: 鍵は PowerShell の標準入力だけで渡す(引数・環境変数・一時ファイルに入らない)。PowerShell は Windows の決まった場所の1つだけから起こす。保存先はネットワークの共有・相対の道・リポジトリの中を断り、リンクは追わない。暗号化した塊に鍵がそのまま入っていないかを確かめてから書く。失敗の文は固定。試験は一時フォルダとにせの暗号化だけ。公開リポジトリに鍵・個人のことはない。

## 軽い指摘と対応
| # | 中身 | 対応 |
|---|---|---|
| 1 | 鍵の貼り直しで保存に失敗すると、前の鍵が残り、次の起動で黙って使われる | 直した(貼り直しで保存できなければ、前の鍵を消して知らせる) |
| 2 | 上のフォルダ(`%LOCALAPPDATA%\Next5MinsAI`)がジャンクションだと、別の場所へ書ける(作れるのは同じ Windows の利用者だけ) | まだ(本当の場所をもう一度確かめる案) |
| 3 | 試験の中の守りは、保存先を渡さないときだけ効く | まだ(いまの試験に実害なし) |
| 4 | 試験の足りない所(PowerShell で戻す流れ・リンク・時間切れ・--new-key と --delete-key の流れ)・一時フォルダの片づけ | まだ |
| 5 | 予行の .bat に `@echo off` がない(見た目だけ) | 直した |

## 確かめていない所
- 本物の PowerShell と DPAPI での保存と復号(動かしていない)。
- サーバーのファイルを出す道から、鍵のフォルダへ回り込めないか(今回の範囲外。出せても暗号化した塊だけ)。
